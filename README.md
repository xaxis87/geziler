# Başka Başka Diyarlar - Burak ÜNAL

Kişisel gezi blogu web sitesi.

## 📖 Hakkında

Bu web sitesi, Burak ÜNAL'ın gezi deneyimlerini ve bisiklet turlarını paylaştığı kişisel bir platformdur.

## 🌍 İçerik

- **Ana Sayfa**: Siteye genel bakış
- **Gezilerim**: Farklı ülkelere yapılan gezilerin fotoğrafları ve hikayeleri
- **Blog**: Gezi yazıları ve deneyimler
- **Bisiklet Turlarım**: Bisiklet turları ve rotaları

## 🚀 Teknolojiler

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages

## 📁 Proje Yapısı

```
geziler/
├── index.html          # Ana sayfa
├── gezilerim.html      # Geziler sayfası
├── blog.html           # Blog sayfası
├── bisiklet.html       # Bisiklet turları sayfası
├── styles.css          # Ana stil dosyası
├── gezilerim.css       # Geziler sayfası stilleri
├── script.js           # JavaScript dosyası
├── images/             # Görseller klasörü
│   ├── blog/          # Blog görselleri
│   └── trips/         # Gezi görselleri
└── design/            # Tasarım PDF dosyaları
```

## 📸 Görseller

Görseller `images/` klasörüne yüklenmelidir:
- Blog görselleri: `images/blog/`
- Gezi görselleri: `images/trips/`

## 🌐 Canlı Site

Site GitHub Pages üzerinden yayınlanmaktadır.
